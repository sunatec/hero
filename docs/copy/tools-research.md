## `/tools` 链上工具箱

- **label**：链上工具箱 · Monitoring Room
- **H1**：链上工具箱
- **引言**：档案室隔壁的监控室。8 个自研监控模块全天运行，异动实时推送到成员频道；其中有明确方向的交易信号，会登记进台账。
- **ticker**：模块 {total} · 运行 {member} · 测试 {beta}
  - 「本月推送」只有能真实统计时才显示，否则不显示
- **筛选**：全部 {n} · 衍生品 · 机构资金 · 聪明钱 · 链上行为 · 定制
- **图例**：运行中 · 成员 / 测试中 / 规划中
- **窗格底栏**：关联台账 {k} 份 → · 详情（有 url 时加：打开工具）
  - 没有关联台账时显示「关联台账 —」
- **ROADMAP 区块标题**：规划中
- **页脚说明**：模块数据仅供研究参考，存在延迟与误报；推送内容不构成投资建议。模块公开后，可以在对应卡片上直接打开使用。
