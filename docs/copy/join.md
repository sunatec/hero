## `/join` 申请加入

- **label**：申请加入 · Apply
- **H1**：申请加入
- **引言**：申请制。提交后，官方管理员会通过 TG 联系你，确认方案与价格。

### 左栏

**流程**
1. **提交申请** — 填写右侧的简短问卷，约 2 分钟
2. **官方联系** — 管理员通过 {telegram.handle} 联系你。请先在「官方渠道验证」页核对账号
3. **确认方案** — 选择季度、半年或年付，确认最终价格
4. **付款入群** — 付款后加入成员频道与成员群

**参考价**
- 季度 {quarter} BNB 起 · 半年 {half} BNB 起 · 年付 {year} BNB 起
- 以 BNB 计价，会根据 BNB 价格、社群阶段与系统投入调整，以管理员付款前的最终确认为准。

**名额**
- {batch.name} · {seats} 席 · 每日审核 {reviewPerDay} 位
- `status = full` 时：本批已满。你仍然可以提交申请，我们会在下一批开放时按提交顺序联系你。

**规则**
- 不设试用 · 售出后不退款 · 禁止转发与转售 → 服务条款

**防骗**
- 付款前，请在「官方渠道验证」页核对联系你的账号{和收款地址}。除了回复你的申请，管理员不会主动私信你，也不会向你索要私钥、助记词或验证码。
