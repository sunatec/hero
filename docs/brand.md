## 1. 名称

| 用途 | 写法 | 说明 |
|---|---|---|
| 主名 | **0xInChain** | 驼峰写法，读作 "0x · In · Chain"，与 X handle 一致 |
| 中文副名 | **链上情报局** | 中文语境下可以单独作为标题使用 |
| 英文副名 | *On-chain Intelligence Bureau* | 用于 `/en` 页面和英文元信息 |
| 组合 | 0xInChain 链上情报局 | 中英之间用一个空格，不用「/」「｜」「·」 |

**不要这样写**：`0xInchain` · `0XINCHAIN` · `0x InChain` · `OxInChain`（字母 O 代替数字 0）· `TwitterInsider`

上线时同步修改 Linktree、Notion、X 显示名中的旧写法（见 WEBSITE_PLAN 附录 B）。

## 2. 定位

- **一句话（中文）**：面向中文实战交易者的链上情报局——用自研监控捕捉资金异动，用公开台账为每一条信号负责。
- **One-liner (EN)**：An on-chain intelligence bureau for traders — we track where capital moves, and we keep a public ledger of every call we make.
- **Hero 主张**：把链上资金的每一次异动，整理成可复盘的情报档案。
- **核心价值**：可验证 Verifiable · 有依据 Reasoned · 敢记录失败 Accountable
- **关键词**：情报 · 证据 · 实战 · 可复盘 · 克制
- **身份**：Professional On-chain Intelligence（主）+ Alpha Community（承接转化）

## 3. 人格与语气

**人格**：一位冷静、严谨的情报分析员，偶尔会眨一下眼（柴犬探员形象负责这一面）。专业但不端着，自信但不许诺。

**写作原则**

1. **先事实，后观点**：给出时间、来源、数字，再给判断
2. **失败照常写**：「这条信号已止损，−8.2%」和「命中」用同样的语气
3. **讲机制，不讲结果**：说「OI 异动 + 聪明钱集群同步建仓」，不说「又一个百倍币」
4. **筛选靠礼貌**：「适合有自己交易体系的人」，而不是贬低不适合的人
5. **不催促**：不写倒计时，不写「最后」，不写「立即」

| 要这样写 | 不要这样写 |
|---|---|
| 申请加入 · 查看信号台账 · 阅读方法论 | 立即抢占 · 马上上车 · 最后名额 |
| 第二批 · 20 席 · 每日审核 1 位 | 仅剩 3 席！手慢无 |
| 结案收益 +18.4%（最大涨幅 +41.0%） | 暴涨 41%！ |
| 过往表现不代表未来结果 | 跟着我们就能赚 |
| 适合 / 不适合 | 巨婴、韭菜、破防（Notion 原文需要改写） |

### 3.1 违禁词清单（M3 起进入 CI 扫描 `scripts/lint-copy.ts`）

```
稳赚 保本 必涨 必赚 财富自由 躺赚 暴富 翻倍保证 无风险 零风险
100% 胜率高达 百分百 错过就亏 错过再等 最后名额 最后机会 仅剩 手慢无
上车 梭哈 内幕
```

- `内幕` 只能出现在引用或解释性上下文中，比如「我们不提供内幕消息」，这种情况走白名单
- `100%` 可以出现在非收益语境中（例如图表坐标轴），同样走白名单

### 3.2 中文排版

- 中文和英文、数字之间加一个半角空格：`覆盖 4 条链`、`CoinGlass Pro API`
- 百分比保留 1 位小数，带符号：`+18.4%` `−8.2%`（负号用 U+2212 `−`）
- 时间统一写成 `2026.10.14 09:12 (UTC+8)`；机器可读的地方用 ISO 8601
- 币种写成 `$ASSET`，全大写
- 全角标点；引号用「」，嵌套时用『』

## 4. 字标（Wordmark）

文件位于 `design/wordmark/`：

| 文件 | 用途 |
|---|---|
| `wordmark-horizontal.svg` | 主字标，用于深色底（骨白色加印章红斜杠） |
| `wordmark-horizontal-on-light.svg` | 浅色底版本（墨色加深印章红斜杠），用于打印或第三方平台 |
| `wordmark-lockup.svg` | 中英组合版：字标 + 分隔线 + 链上情报局 + ON-CHAIN INTELLIGENCE BUREAU |
| `favicon.svg` | 只用带斜杠的 0，放在墨灰方块里 |

**构造**：9 个字形全部用几何路径手工构造，**不依赖任何字体**。网格参数：大写高 60、x-height 44、线宽 7、字宽 36、字距 10。结构借鉴打字机等宽字体，和「档案」的隐喻一致。

**标志性细节**：带斜杠的 **0**，斜杠用印章红。它既是代码和账本里区分 0 与 O 的写法，也像盖章时的一笔，是整个品牌最小的识别单元。favicon 就用它。

**使用规则**

- 最小尺寸：横版高度 ≥ 16px（数字屏幕）；更小的场景改用 favicon
- 留白：四周至少留出一个「0」的宽度
- 斜杠永远是红色，字形永远是单色；不要给字标加渐变、描边、阴影或发光
- 不要拉伸、倾斜、重新排列字形，也不要只把「In」高亮
- 组合版中的中文目前还是 `<text>` 元素，**M3 字体入库后需要转曲**，转曲后才算正式资产

## 5. 色彩（摘要，完整值见 tokens.json）

| Token | 值 | 角色 | 对比度（在 ink-0 上） |
|---|---|---|---|
| ink-0 / 1 / 2 | #14161A / #1B1E23 / #252930 | 页面 / 档案卡 / 悬停 | — |
| bone | #E9E4D8 | 正文 | 14.28 |
| bone-dim | #A8A398 | 次要文字 | 7.21 |
| **stamp** | **#E8604A** | 唯一强调色：印章、关键句、描边 | 5.35 |
| stamp-fill | #A93322 | 主按钮底色（配 bone 文字，对比度 5.20） | — |
| dossier | #C9A96A | 编号、批注、元信息 | 8.08 |
| gain / loss | #6FBF8E / #E07A68 | 只用于数据 | 8.21 / 6.17 |
| redact | #0B0C0E | 涂黑条 | — |

**规则**

- 强调色**只有印章红一个**。每一屏里，印章红只出现在：印章、主 CTA、最多一个关键句
- gain / loss **只出现在数字上**，不用于背景、按钮或装饰
- M1 的调整：原计划的 #D6452F 当小字用对比度只有 4.1，按钮上的骨白字只有 3.48，都没达到 AA。现在拆成 `stamp`（文字和印章用）与 `stamp-fill`（按钮底色用）两个 token
- `stamp` 在 ink-2（悬停底色）上对比度为 4.31，只能用于大号粗体或非文字元素
- V1 只做深色

## 7. 版式语言

- **档案**：每个区块都是一页档案。左侧批注栏放编号、日期、来源；区块之间用「档案夹分隔线」隔开：一条细线，左端带 `§ 05 标题` 标签
- **印章**：双线圆角矩形，旋转 −6°，只用印章红。6 种状态：进行中 · 命中 · 失效 · 止损 · 超时 · 作废。**失败的印章和成功的同样大小、同样显眼**
- **涂黑**：墨黑实心条，长度约等于原文长度；悬停时显示「成员可见 · 申请加入 →」。进行中信号的真实内容**不能出现在代码里**
- **窗格**（只用于工具箱）：没有圆角，标题栏写 `M-01 / DERIVATIVES`，右边是状态点；数据用 Martian Mono 等宽数字

## 8. 柴犬探员使用规则

| 可以用 | 场景 |
|---|---|
| 基础款叉腰、「That's me!」 | 主理人档案照（首页、/about），放在照片框里，用回形针别住，轻微降饱和 |
| 点赞眨眼 | 申请提交成功页 |
| 基础款或思考姿势 | 404 页、台账空状态 |

| 不要用 | 原因 |
|---|---|
| Winner 奖杯、皇冠 | 暗示赢钱，和不做收益承诺的原则冲突 |
| 情人节、春节系列 | 只用于 X / TG 的节日运营 |
| 放在 Hero 或战绩区 | 会削弱专业感 |

**素材要求**：透明背景 PNG（≥ 1200px）或 SVG，**不能带 AI 生成工具的水印**。`images/` 里现有的截图只能作为参考。

## 9. 动效原则

1. 没有任何动画会阻塞阅读：首屏文字在第一帧就可见
2. 动效只用在「档案动作」上：画线、盖章、打印、涂黑
3. 只播放一次，不循环
4. 所有动效都要支持 `prefers-reduced-motion`
5. 时长不超过 400ms（数字滚动除外，≤ 800ms）
